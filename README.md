# مشروع "غزة تعمل" (Gaza Works)
منصة لإدارة فرص العمل المؤقتة وإعادة الإعمار.

## التقنيات المستخدمة:
- HTML5 & CSS3
- Bootstrap 5 (Responsive Design)
- JavaScript (ES6) - Logic & Data Rendering
- jQuery - Animations & Events Handling

## أهم المميزات:
- عرض ديناميكي للوظائف من مصفوفة بيانات.
- ميزة البحث الفوري (Instant Filter).
- تغيير حالة الوظيفة (متاح/مكتمل) دون تحديث الصفحة.
- دعم الوضع الليلي (Dark Mode).
- نموذج تسجيل متكامل مع التحقق من البيانات.
